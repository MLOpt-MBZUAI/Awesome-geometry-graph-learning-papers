# Awesome Geometric Graph Learning Papers

A curated list of research at the intersection of graph learning and geometry: equivariant neural networks, geometric and topological representations, manifold and curvature methods, molecular geometry, and geometry-aware graph generation.

The [comprehensive 2025-2026 ICLR / ICML / NeurIPS index](TOP_CONFERENCE_2025_2026.md) contains **120** verified papers. The sections below provide a shorter set of 61 representative highlights.

## Scope and coverage

- **Venues:** ICLR, ICML, and NeurIPS main conference only.
- **Years:** 2025 and 2026, verified through **2026-08-21**.
- **Included:** papers whose core methodological contribution is geometric graph learning.
- **Excluded:** generic graph learning, low-rank geometry unrelated to graphs, workshops, position papers, submissions, withdrawn papers, and arXiv-only work.
- **NeurIPS 2026:** proceedings were not available on the verification date.
